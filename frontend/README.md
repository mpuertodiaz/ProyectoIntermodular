# frontend/

Interfaz de la aplicación: **HTML, CSS y JavaScript** con **Bootstrap 5.3**.

- `index.html`: página principal. De momento es una página de prueba de la guía de estilo.
- `css/estilos.css`: colores, fuentes y tamaños de la guía de estilo de Figma. Personaliza Bootstrap.
- `js/main.js`: JavaScript principal. Tiene la dirección del backend (`API_URL`).
- `lib/bootstrap/`: archivos de Bootstrap. No se modifican.

Para verlo, abre `index.html` en el navegador (o usa Live Server en VS Code).
