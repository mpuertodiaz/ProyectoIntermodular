# frontend/

Interfaz de la aplicación: **HTML, CSS propio y JavaScript**.

- `index.html`: de momento es la página de prueba de la guía de estilo, con los colores y las tipografías.
- `componentes.html`: catálogo con todos los componentes (botones, campos y tarjetas).
- `css/estilos.css`: guía de estilo de Figma en variables CSS (colores, fuentes, tamaños, espacios y esquinas), estilos base y adaptación al móvil.
- `css/componentes.css`: estilos de los componentes. Usan las variables de `estilos.css`.
- `js/main.js`: JavaScript principal. Tiene la dirección del backend (`API_URL`).

Para verlo, abre `index.html` en el navegador (o usa Live Server en VS Code). Hace falta internet para cargar las fuentes de Google Fonts.

La elección del CSS propio está explicada en `docs/framework_css.md`.
