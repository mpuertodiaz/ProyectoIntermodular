# App Web de Agilidad Mental (MindSprint)

Proyecto Intermodular - 2º DAM
Alumnos: Pablo de la Rosa y Manuel Puerto.

## Estructura del Proyecto
- `/backend`: Lógica del servidor y conexiones.
- `/frontend`: Interfaz web, HTML, CSS y JavaScript[cite: 19].
- `/database`: Scripts SQL de esquemas y datos de prueba[cite: 20].
- `/docs`: Documentación del proyecto y diseño del CRUD[cite: 20].

## Instrucciones de Arranque
1. Configurar la base de datos ejecutando los scripts de la carpeta `database/`.
2. Copiar el fichero `.env.example` a `.env` y rellenar los datos.
3. Arrancar el servidor de backend y el entorno frontend.
