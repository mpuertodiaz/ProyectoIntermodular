# database/

Scripts de la base de datos MySQL.

- `schema.sql`: borra y crea la base de datos `mindsprint` con sus tablas.
- `datos_prueba.sql`: inserta los datos de prueba. Se ejecuta después de `schema.sql`.
- Diagrama de la base de datos generado con MySQL Workbench.

Cómo ejecutarlos: ver el `README.md` principal.
